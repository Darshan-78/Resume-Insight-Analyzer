# Resume Insight Analyzer

An AI-powered resume analysis tool built for software/tech job seekers. Upload your resume, compare it against a job description (or 25+ predefined tech roles), and get instant, actionable feedback — skill gaps, grammar issues, ATS-friendliness, and a personalized 3-month learning roadmap generated by AI.

🔗 **Live Demo:** https://resume-insight-analyzer-murex.vercel.app/

---

## Features

- **Multi-format resume upload** — PDF, DOCX, and DOC support (or paste resume text directly)
- **Dynamic Job Description matching** — paste any job description and get skill-gap analysis, or choose from 25+ predefined tech roles
- **Technical vs Soft Skills categorization** — matched/missing skills are split into technical and soft skills, with priority labels ("Critical" vs "Nice to have") based on how the JD frames each requirement
- **Grammar & Spelling Review** — powered by LanguageTool, tuned to avoid false positives on proper nouns, institution names, and technical terms
- **Resume Health Check**
  - Missing-section detection (Education, Skills, Certifications, etc.)
  - Bullet-point strength feedback (flags weak verbs and bullets missing measurable impact)
  - ATS-friendliness check for PDF uploads (detects layout risks like multi-column formatting or embedded images)
- **AI-Powered Learning Roadmap** — opt-in, generates a personalized 3-month roadmap (via Google Gemini API) based on your specific skill gaps, complete with resources and resume-bullet suggestions for demonstrating soft skills
- **Downloadable PDF Report** — a complete, styled report with all analysis sections, matching the web dashboard
- **Score History** — past analyses are saved per-session (privacy-isolated, no login required) with a trend chart showing score improvement over time
- **Privacy-first** — session-based data isolation via cookies, a "Clear History" option, and automatic 30-day data expiry
- **Mobile-responsive UI** — clean, tabbed results view (Overview / Skills / Health Check / Grammar / Roadmap) to avoid long scrolling

## Tech Stack

**Backend:** Java, Spring Boot, Spring Data JPA (Hibernate), PostgreSQL
**Document Parsing:** Apache PDFBox (PDF), Apache POI (DOCX/DOC)
**Grammar Engine:** LanguageTool
**AI Integration:** Google Gemini API (roadmap generation)
**Frontend:** HTML, CSS, JavaScript, Chart.js (score visualizations)
**Deployment:** Docker, Render / Vercel

---

## How It Works

1. Upload a resume (PDF/DOCX/DOC) or paste the text directly
2. Choose an analysis mode:
   - **Compare with Job Description** — paste any job posting for a dynamic, role-specific match
   - **Predefined Role Matching** — select from 25+ common tech roles (Frontend, Backend, DevOps, Data Science, etc.)
3. Get a full breakdown: match score, categorized skill gaps, grammar review, resume health check, and ATS risk flags
4. Optionally generate a personalized 3-month AI roadmap to close your skill gaps
5. Download the full report as a PDF, or track your progress over time via score history

---

## Project Scope

This tool is intentionally focused on **technical/software engineering roles**. Rather than building a generic resume checker for every industry, the goal was to go deep on accuracy for tech-specific skills, synonyms (e.g. JS/JavaScript, ReactJS/React), and role-specific matching — support for non-technical domains is a possible future direction, not the current focus.

## Local Setup

### Prerequisites
- Java 17+
- Maven
- PostgreSQL
- A Google Gemini API key ([get one free here](https://aistudio.google.com))

### Steps

```bash
git clone https://github.com/Darshan-78/Resume-Insight-Analyzer.git
cd Resume-Insight-Analyzer/resumeinsight
```

Create `src/main/resources/application-local.properties`:
```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/resumeinsight
spring.datasource.username=postgres
spring.datasource.password=your_postgres_password

gemini.api.key=your_gemini_api_key
```

Run:
```bash
./mvnw spring-boot:run
```

Visit `http://localhost:8080`
