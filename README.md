# Resume Insight Analyzer

A rule-based Resume Role Recommendation Web Application built using Java Spring Boot and HTML, CSS, JavaScript.

## Features

- Detects technical skills from resume text
- Matches resume with predefined job roles
- Calculates role match percentage
- Provides best role recommendation
- Shows role ranking
- Displays feedback based on score
- Supports target-role analysis using dropdown selection
- Downloadable report generation
- Responsive dashboard-style UI

## How It Works

1. User pastes resume text
2. System detects skills
3. Skills are matched with predefined role skill sets
4. Match percentage is calculated
5. Best role recommendation and feedback are displayed
